# Swiggy-Food-Delivery-Data-Analysis


End-to-end **Swiggy data analysis project** using **SQL Server, T-SQL, Star Schema, and Power BI**.

### 📊 Project Highlights

* Analyzed **197,401 (~2 lakh) Swiggy records**
* Performed data cleaning, validation, and duplicate removal
* Built a **Star Schema** with fact and dimension tables
* Created KPIs for orders, revenue, price, and ratings
* Performed city, state, restaurant, dish, price, and rating analysis
* Developed a Power BI dashboard

### 🔑 Key Results

| KPI             |               Result |
| --------------- | -------------------: |
| Total Orders    |              197,401 |
| Total Revenue   |       ₹53.00 Million |
| Avg. Dish Price |              ₹268.50 |
| Avg. Rating     |                 4.34 |
| Top City        |   Bengaluru – 20,072 |
| Top Restaurant  |  McDonald's – 13,528 |
| Top Dish        | Veg Fried Rice – 321 |
